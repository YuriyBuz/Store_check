🛒 Моніторинг Залишків та Цін (Brand Stock Checker)

Цей веб-додаток на базі Streamlit дозволяє автоматично моніторити наявність, ціни та знижки на товари певних брендів у популярних українських мережах супермаркетів.

🏪 Підтримувані мережі

Сільпо (silpo.ua)

Novus (zakaz.ua)

Varus (zakaz.ua)

🚀 Як запустити локально

Встановіть Python 3.9+ та Node.js.

Клонуйте цей репозиторій.

Встановіть залежності:

pip install -r requirements.txt


Запустіть додаток:

streamlit run web_app.py


☁️ Як розгорнути на Streamlit Community Cloud

Завантажте цей код у свій публічний або приватний репозиторій на GitHub.

Зареєструйтесь на share.streamlit.io.

Натисніть "New app".

Оберіть свій репозиторій, гілку (main) та головний файл — web_app.py.

Натисніть Deploy. Сервер автоматично підтягне Node.js (з packages.txt) та Python-бібліотеки (з requirements.txt).
